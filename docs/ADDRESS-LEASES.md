# 用户地址租约

主控支持为用户配置两种地址分配方式，配置入口位于管理后台的“用户管理 → 地址租约”。

## 自动分配

自动模式首次连接时从当前双栈地址池分配地址，之后复用用户已有租约。用户离线后地址仍计入占用，避免地址在重连时漂移或被其他用户抢占。

如果地址池缩小导致自动租约落在新池外，主控允许保存这次池变更，但不会在线改写地址；用户下一次连接时才会从新池重新分配。活动连接占用池外地址时，池变更会被拒绝，避免现有隧道突然失效。

## 固定分配

固定模式有两种来源：

- 从地址池分配：主控选择当前池中的空闲双栈地址；已有合法租约会优先复用。
- 手动指定：管理员可以填写池内或池外的合法单播 IPv4/IPv6 地址。两侧都填写时可以完全独立于地址池；只填写一侧时，仅当该地址属于地址池时主控才会按偏移补齐另一侧。

从地址池分配时会排除 IPv4 网络地址、网关地址和广播地址。手动地址不受地址池范围限制，但仍必须是合法单播主机地址，不能填写 CIDR、未指定地址或组播地址。

主控会拒绝以下地址：

- IPv4 网络地址、网关地址和广播地址；
- 从地址池分配时不在当前地址池内的地址；
- 只填写池外单侧地址而无法推导另一侧的情况；
- 已被其他用户的固定租约、在线设备或离线设备占用的地址。

固定地址会计入地址池占用，即使用户尚未首次登录。地址池耗尽时，已有合法固定租约仍可连接；新的自动租约会收到明确的地址池耗尽错误。

固定租约可以在用户离线时迁移，设备的配置版本会递增，旧地址随之释放。用户仍有活动连接时，修改固定地址会返回冲突，必须先断开连接。

## API

管理员接口：

```text
POST /v1/admin/users/{username}/address-lease
```

自动分配：

```json
{
  "address_mode": "automatic",
  "reserved_ipv4": null,
  "reserved_ipv6": null
}
```

固定分配：

```json
{
  "address_mode": "fixed",
  "reserved_ipv4": "10.88.0.20",
  "reserved_ipv6": "fd88:1000::14"
}
```

租约策略保存在主控用户存储文件中。旧用户记录没有新增字段时按自动分配兼容处理；主控启动时会校验固定租约的格式、池范围和重复保留，发现不一致会拒绝启动并保留原始存储文件。
